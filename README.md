# airshow-config

航展哨兵 APK 的 OTA 配置仓（公开）。

- `urls.json`：监控通道池 + 售票日历
- 只包含公开购票通道信息，**不含任何个人信息**
- APK 每 10 分钟自动拉取本文件（最坏延迟约 10.5 分钟），云端更新后无需重装

⚠ 数据状态：`assumed`（推测）。已由官方公告原图 OCR 证实的仅：大麦独家代理、10月19日启动销售、10月16日发布会。
**售票日历与 12:00 开售时刻未经官方证实**，将在 10月16日发布会后逐项核实更新为 `verified`。
每条 verified 数据在 docs/_crawl/ 保有公告原文截图存档。
